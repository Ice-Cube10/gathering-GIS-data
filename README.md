# gathering-GIS-data
Gathers GIS spatial data from multiple files using GeoPandas and puts that information into a readable dataframe.

To run the file:
Navigate to the folder where it is downloaded in your command line (By default Downloads -> gathering-GIS-data-main)
Once inside the folder, type "python3 main.py" and the program should start
The user can then filter by state or just print the whole list (The list includes every US county so it is quite long)
Once the user is finished they can simply press Enter without entering any state name or number and the program will exit.
